# mathgame

Math activities built by manipulating objects on the infinite canvas,
like the levels of a logic game (think Sokoban).

Students can make lots of mistakes, figure things out by themselves,
and get their own little *eureka* moments.

Site: https://mathgame.fr (currently running the previous version,
from [a-user-interface](https://github.com/teachingbeforedying/a-user-interface)).
